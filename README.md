# 📂 Gerenciador de Projetos e Tarefas (Vanilla JS)

Um sistema simples de gerenciamento de projetos e tarefas desenvolvido para exercitar conceitos fundamentais de lógica de programação, orientação a objetos e manipulação de dados em JavaScript puro (ES6+).

## 🚀 Funcionalidades
- Modelagem de Entidades (`Usuario`, `Projeto`, `Tarefa`).
- Persistência e gerenciamento de dados local/JSON.
- Regras de negócio puras desacopladas de frameworks.

## 🛠️ Tecnologias
- JavaScript (ES6+)
- JSON
